# UML Diagram Explanation

## Use Case Diagram
    This diagram shows the interactions between the actors (Member and Librarian) and the library system. It represents the functions user can perform, such as borrowing, returning, and managing books.

## Class Diagram
    This diagram shows the classes in the library system, their attributes, methods, and relationships between classes such as book, copy, member, loan, and librarian.

## Sequence Diagram
    This diagram shows the order of communication between objects when  a member borrows a book.

## State Machine Diagram
    This diagram shows the different states of a book copy, such as available, reserve, borrowed, and lost.
